1. Resources in path segment of the URL should be plural form.  eg: api.example.com/v1/conversations (all conversations)
2. When we are referring to a single resource, we still use an plural form for the resource/path with an id in the path. eg: api.example.com/v1/conversations/{conversation_id} (one conversation)
3. All REST OPERATIONS (GET, PUT, PATCH, DELETE) are indempotent in nature except the POST OPERATION. When we say indempotent, we mean that there is no side-effects of the same request being sent more than once.
